# Autonomous Newsroom

Confer Inc. AI/ML take-home assessment.

A self-updating news application delivered by autonomous agents running on OpenClaw and Hermes.

## Who writes what

| Path | Author |
|---|---|
| `app/` (product code and tests) | Autonomous agents, through tickets and pull requests |
| `infra/`, `agents/`, `orchestrator/`, `scripts/`, `docker/`, `docs/` | Human setup with AI planning assistance, disclosed in DELIVERY.md |

See `docs/agent-team.md` for the agent roster, ticket flow and how to run the team, and
`docs/agent-identity.md` for agent identities, permissions, and merge gates.

## Delivery report

`DELIVERY.md` is the hand-over document: live URL, agent roster, ticket flow, what each agent did, what
broke, the token and model report, trace excerpts, infrastructure notes, disclosures and how to reproduce.
